Codex와 대화

메시지와 이 콘텐츠의 저장된 기획·피드백을 로그인된 Codex CLI에 전달합니다. 질문하기는 파일을 수정하지 않습니다.

추가 질문에는 선택지나 직접 입력으로 답할 수 있습니다. 명령·파일 변경 승인은 별도로 표시하며 자동으로 승인하지 않습니다. 구현 후 검사·빌드를 실행해 결과를 확인하세요.
