실제 제작 · 빌드 화면

콘텐츠별 별도 Git 작업 공간에서 제작합니다. 본문 초안을 만든 뒤 콘텐츠별 시각 자료를 추가하고 빌드 화면을 확인하세요. 새로운 시각 자료나 상호작용은 구현 요청으로 확장할 수 있습니다.

외부 에이전트 전달

Studio 안에서 대화나 에이전트를 실행하지 않습니다. 저장된 기획과 피드백을 현재 버전에 묶어 파일로 내보낸 뒤 OpenCode 또는 다른 도구에서 작업하세요.

구현 패킷은 위의 작업 공간 경로를 포함합니다. 외부 작업 뒤 결과 JSON을 가져오면 Studio가 현재 소스 지문을 계산해 해당 기획 버전에 연결합니다. 이는 실행 증거나 승인이 아닙니다.

검토와 피드백
버전에 묶인 독립 리뷰 결과만 위의 전달 영역에서 가져옵니다. 내용 가치와 전체 연결성은 대본과 독립적인 풀이 재구성으로 검토하며, 화면·빌드만으로 대신할 수 없습니다. 음성·영상 실측과 화면 검토는 별도입니다.
