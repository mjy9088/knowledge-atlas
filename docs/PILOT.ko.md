# 첫 콘텐츠 파일럿 — 모순이 있으면 정말 무엇이든 증명할 수 있을까?

**콘텐츠 ID:** `experience:logic.explosion.ko`  
**범위:** 과학 전반 지식 지도를 위한 제작 워크플로 테스트. 형식논리는 첫 사례일 뿐 전체 사이트의 편집 방향이 아니다.  
**목표:** 웹 경험 1개 + 영상 projection 1개 + 출처/주장/상태/피드백/검사 수직 경로.  
**예상 영상 분량:** 5~8분(편집 결과에 따라 조정). '미리 흥미를 끌 소재'로 기획하지 않는다.

## 1. 독립적으로 전달할 지식

- **모순 폭발(ex falso quodlibet):** 일반적인 고전 자연연역에서 전제로부터 `P`와 `¬P`가 성립하면 모순 `⊥`를 도출하고 임의의 명제 `Q`를 도출할 수 있다. `⊥` 제거 규칙이 이 역할을 한다.
- 이 결론은 **논리체계에서의 도출 가능성**이며, 현실의 모든 주장이 참이 되었다는 뜻이 아니다.
- 어떤 공리계를 구성하는 명제들의 증명이 모순을 만들면 그 고전논리 체계 안에서 모든 문장을 증명할 수 있게 된다. **왜 CH 독립성 설명에 ZFC의 일관성 조건이 붙는지**와 연결된다. 단 이 영상은 CH 독립성 정리의 증명이 아니다.
- 모순 폭발을 인정하는 것은 고전논리만의 독점적 특징이 아니다. 통상적인 직관주의 논리에서도 폭발이 가능하다. 폭발을 허용하지 않는 일부 `paraconsistent` 논리로 분기 가능.
- 전제 중 하나를 제거해 **보여주는 증명 경로**가 끊어졌다고 하여 다른 경로로도 결코 증명할 수 없다는 것이 입증된 것은 아니다.

### 처음부터 금지할 오해

1. `P`와 `¬P`가 입력되면 실제 세계의 모든 명제가 참이다.
2. 모순 폭발 = 오직 고전논리에만 있다.
3. 전제가 하나 빠진 뒤 화면의 도출이 실패하면 해당 결론의 독립성이 증명되었다.
4. 이 간단한 규칙 자체가 `Con(ZFC) ⇒ CH 독립`을 증명한다.
5. 결과가 컴퓨터에서 출력되었으므로 해당 주장의 현실적 진실이 확인되었다.

- **forall x: Calgary** HTML 17장 자연연역의 Basic rules for TFL. `⊥`와 폭발 규칙, 그리고 그 설명: https://forallx.openlogicproject.org/html/Ch17.html
- HTML 책 안내의 revision `c5cb415`(2026-09-27): https://forallx.openlogicproject.org/html/
- Open Logic Project (보조, 정확한 section은 본 제작 단계에서 별도 지정): https://openlogicproject.org/

**출판 전 해야 할 일:** 인용할 정확한 source span/판본을 `sources`에 고정하고, 화면 표시·출처 패널 및 필요한 권리 고지 검수. 파일럿 JSON은 내용 검토 대기 상태다.

## 3. 장면과 조작

### Scene 1 — 전제와 결론

- 사용자는 `P`와 `¬P` 전제를 각각 토글할 수 있다.
- 임의 결론 기호 `Q`, `R`, `S` 중 하나를 선택한다(사용자가 실제 문장이라고 착각하지 않게 '임의 명제 기호'로 명시).
- 두 전제가 주어지면 단계별 증명 `P`, `¬P`, `⊥`, `Q`를 시각화한다.
- 전제가 부족하면 '이 증명 경로는 구성되지 않음'을 표시한다. '결론이 거짓'이라고 말하지 않는다.
- 가정·규칙 이름·현재 적용 가능한 규칙·접근성 대체 텍스트를 제공한다.

**모형과 화면을 분리:** `packages/models/explosion.mjs`의 순수 함수를 이용한 간단한 시범 추론이며, 임의 공식의 참/거짓을 판정하는 정식 정리증명기는 아니다. 장기적으로 검증 가능한 AST·proof object·검사기를 연결한다.

### Scene 2 — 증명과 참의 차이

- 가정이 모순적일 때 도출될 수 있는 결론과, 그 결론을 현실의 사실이라고 말하는 것은 다르다는 설명.
- '공리계/전제 집합', '모형/해석', '증명'을 구분하는 작은 다이어그램.
- 추가 인터랙션은 필요할 때만. 단순히 움직이게 하려고 새로운 토글을 만들지 않는다.

### Scene 3 — 지식 지도 연결

- 개념/관계: `contradiction`, `explosion`, `consistency`, `classical logic`, `paraconsistent logic`, `ZFC`, `independence`.
- 모든 링크는 '필수 선행 학습'이 아니라 연결 유형과 짧은 맥락을 제공.
- 구현되지 않은 콘텐츠는 빈 링크로 방치하지 않고 개념 요약/출처 링크 혹은 `준비 중` 표시.

## 4. 영상 projection — 제안하는 경로 (고정 대본 아님)

1. 주제와 사용할 전제/규칙의 범위를 소개한다.
2. `P`, `¬P`를 보이고 `⊥`를 도출한다.
3. 선택한 임의 결론 `Q`를 보여주고 폭발 규칙을 적용한다.
4. 결론을 `R`로 바꿔도 같은 경로가 성립함을 재현한다.
5. 전제 하나를 제거해 **이 증명이** 끊어지는 모습을 보인다.
6. '논리적 도출과 현실의 참'을 명확히 구분한다.
7. 일관성과 ZFC/CH 조건으로 연결하되 그것을 여기서 증명했다고 주장하지 않는다.
8. 참조 자료와 독립적으로 탐색 가능한 웹 버전을 안내한다.

영상 출력은 16:9 1080p/30fps 기준으로 시작 가능. 출처·자막·음성·장면 이벤트 모두 고정된 콘텐츠 manifest를 참조한다. 웹 기본 독해에 이 영상을 필수로 요구하지 않는다.

## 5. 첫 피드백 3건을 실제로 실행

- **F1 시간:** '결론 전에 생각할 시간이 부족하다' → 영상 진행 타이밍만 수정, 지식·웹 모델 유지.
- **F2 의미:** '이 규칙이 현실의 진릿값을 뜻한다고 오해할 것 같다' → 설명과 UI를 동기 수정, 정확성 검토.
- **F3 보호:** 'Scene 1의 승인된 수정은 유지하고 나머지를 다시 구성하라' → 보존된 패치 확인.

각 경우 입력 상태와 버전, diff, 스크린샷/영상 프레임, 테스트 결과, 승인 여부를 기록한다. 피드백에서 만들어진 전역 규칙은 범위/예외/회귀 fixture가 있을 때만 채택한다.

## 6. 필수 테스트

**의미/모형**
- P=true, notP=true이면 `contradiction=true`, Q/R/S 어떤 결론이든 도출 경로가 있다.
- 둘 중 하나 false이면 **현재 폭발 경로**가 없다. 다른 경로의 불가능성 주장을 출력하지 않는다.
- 잘못된 결론 식별자에 적절하게 반응한다.
- UI 표현과 narration이 주장·가정의 의미를 훼손하지 않는다.

**실행/경험**
- 초기/변경/reset/상태 재현, 모바일·키보드 사용, 장면 ID의 안정성.
- 영상 프레임 렌더가 지원되는 시점에는 오디오/자막 타이밍과 화면 요소의 가시성 검사.
- 실제 브라우저 결과(CV/DOM)와 모형 계산 결과 대조.

**권리/출처**
- 출처 ID 및 판본 유효, 권리 확인, 시각 자산마다 별도 권리 기록.

- 웹의 Scene 1 상태가 영상의 같은 장면에서 자동 재현된다.
- 영상 MP4와 자막, 웹 콘텐츠, 자료/정정 정보가 같은 승인 manifest를 공유한다.
- 세 피드백 사례의 부분 수정을 실제 수행하고, 보호된 변경이 살아 있다.
- 생성에 관여한 모델/프롬프트/도구/비용/검사 결과 및 고지 내용을 추적한다.

초기 제공 범위는 첫 장면의 읽기·클릭 데모와 JSON storyboard/검사 코드였다. 추가 추론 실험과 HTML 재생 범위는 아래 §8에 기록한다. 완성된 음성이나 MP4는 아직 없다.

## 8. 사용자 피드백에 따른 추론 실험 확장 (2026-10-16)

`feedback:2026-10-16.inference-video`에 따라 기존 Scene 1과 별도의 `scene:logic.inference.lab`를 추가한다. 기존 모순 폭발의 입력 계약·ID·과학 fixture는 유지한다.

- 최대 8개의 기호 명제 전제와 목표식을 편집한다. 부정·논리곱·논리합·조건문 및 괄호를 지원하며 자연어 의미 분석은 하지 않는다.
- 지원 규칙은 ∧ 제거, → 제거, 모순 도출, ⊥ 제거, 목표 부분식의 ∧/∨ 도입이다. 각 결과에 고유 행 ID·규칙·앞선 참조 행을 남긴다.
- 검색은 불완전하며, 결과가 없더라도 거짓·독립성·증명 불가능성을 판정하지 않는다. 부분증명, → 도입, ∨ 제거는 미지원이다.
- HTML 재생 화면은 계산된 proof와 입력을 복사한 같은 snapshot에서 시점별 단계·강조·자막을 만든다. 자동 재생·시간 이동은 이 결과의 표현이며 새 추론을 생성하지 않는다.
- 후속 사용자 지시에 따라 WebM 내보내기는 이번 범위에서 제외한다. HTML 애니메이션 미리보기와 실제 영상 파일·음성·공개 manifest는 구분한다.

새 규칙의 근거·조건은 `inference-claims.json`, 경험 계약은 `inference.json`에 기록한다. 현재 교재의 §§17.3/17.4/17.7/17.8을 읽고 규칙과 대조했으나, 기존 등록 판본의 정확한 revision·원문 해시·권리 및 사람의 내용 승인은 대기 상태다. 새로운 규칙의 fixture는 기존 정답을 바꾸지 않고 추가하며, 모형 작성자 외 별도 의미 검사도 수행한다.
