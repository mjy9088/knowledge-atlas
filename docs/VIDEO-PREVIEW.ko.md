# 명제 추론의 HTML 재생 미리보기

## 정지 상태에서도 같은 시각적 설명

`apps/web/inference-visual.mjs`의 `mountInferenceVisual(container)`는 웹 탐색에서 선택한 증명 줄을 큰 HTML 카드로 보여준다. `update({premises,goal,proof,step})`의 `step`은 0부터 시작하는 줄 번호다. 사용한 이전 단계 → 적용 규칙 → 현재 결과를 표시하며, 입력 전제인 줄에서는 선택한 가정 카드와 설명만 표시한다. 전제를 다른 줄에서 도출한 것처럼 화살표로 연결하지 않는다. 목표 도달 여부는 선택한 줄이 아니라 전체 탐색 결과임을 명시한다.

순수 함수 `visualForStep`는 기존 증명 줄과 참조만 읽는다. 참조가 없으면 누락 안내를 표시하며 추론을 새로 만들지 않는다. 단계 선택이 바뀌면 도표도 같은 줄로 갱신된다. 카드의 전체 수식은 줄바꿈 가능한 텍스트이므로 좁은 화면에서도 Canvas 축소에 의존하지 않는다.

정지 도표와 재생의 표시 수식·소개·자막은 공통 `displayFormula`를 사용해 입력 별칭 `->`, `!`, `~`, `&`, `|`를 논리 기호로 표시한다. 내부 입력 스냅샷과 증명 줄 ID는 보존한다. 이는 표기 변환이며 수식 평가나 의미 변경이 아니다. 슬라이드를 떠날 때는 재생 API의 `pause()`를 호출해 숨겨진 애니메이션을 멈출 수 있다.

`node --test tests/inference-visual.test.mjs`의 4개 테스트는 기존 의존 관계·수식 보존, 전제와 도출 구분, 잘못된 단계와 빈 결과, 누락 참조 안내를 검사한다. 과학 모형이나 기존 의미 fixture는 변경하지 않는다.

`scene:logic.inference.lab`의 웹 증명과 애니메이션은 `model:logic.propositional.forward`가 반환한 동일한 결과를 사용한다. 재생 코드는 별도로 추론하지 않는다. 기존 모순 폭발 Scene 1의 30초 storyboard와는 별도 미리보기다.

## 구현

`apps/web/inference-video.mjs`의 `mountInferenceVideo(container)`는 960×540, 16:9 Canvas에 재생·일시정지·처음부터·시간 탐색을 제공한다. HTML에서 직접 재생하는 무음 애니메이션이며, 영상 파일 생성이나 TTS는 포함하지 않는다.

`update({premises,goal,proof})`는 입력과 증명 결과의 복사본을 고정하고 처음부터 보여준다. 입력이 바뀌거나 제출한 수식이 잘못되면 UI가 `invalidate(reason)`을 호출한다. 이전 재생을 멈추고 조작·재현 데이터 링크를 비활성화하며, 새 추론을 실행해야 재생할 수 있음을 표시한다. 따라서 이전 증명을 수정 중인 새 입력의 결과처럼 보여주지 않는다.

`createVideoTimeline`은 전제·목표 소개 → 각 증명 줄 → 결과와 한계의 cue를 만든다. 각 줄은 1.8초이며 긴 증명도 압축하지 않는다. `frameAt(timeline,timeMs)`는 이전 재생 이력 없이 해당 시점의 화면 상태·fade/slide 진행률·의존 줄 강조를 계산한다. 브라우저의 reduced motion 설정에서는 움직임을 제거하고 같은 단계·수식·자막을 유지한다. 지원하지 않는 시간은 거부하고 끝 이후는 마지막 상태를 유지한다.

현재 단계가 부드럽게 나타나고, 해당 단계의 `dependsOn` 참조 줄을 강조한다. 화면에 최근 6개 줄을 보여주며 앞선 줄이 있으면 생략 범위를 표시한다. 전체 증명은 웹 증명에 남는다. 수식은 가능한 범위에서 줄바꿈·글자 크기 조정을 거치며, 공간에 맞지 않는 긴 수식은 **긴 수식 안내**로 바꾼다. 수식을 조용히 잘라 다른 완전한 공식처럼 표시하지 않는다. Canvas 아래 텍스트에는 현재 단계의 전체 수식·규칙·참조를 보여준다.

좁은 화면에서는 Canvas 대신 같은 `frameAt` 결과로 만든 HTML 단계 카드를 보여준다. 현재 단계/전체 단계 수, 전체 수식, 규칙, 의존 단계의 전체 수식을 줄바꿈 가능한 텍스트로 표시한다. 소개 시점에는 전제와 목표, 마지막 시점에는 결과를 보여주며 입력 변경 시 카드도 함께 숨긴다. 단계가 바뀔 때만 DOM을 갱신한다.

접힌 ‘재현 데이터와 자막’에는 같은 타임라인의 VTT와 입력·증명·cue를 담은 JSON이 있다. 재생에는 다운로드가 필요하지 않으며 네트워크나 외부 시각 자산을 사용하지 않는다.

## 확인 방법

1. `A`, `A -> B`를 전제로, `B`를 목표로 추론한다.
2. 재생·일시정지하고 시점을 앞뒤로 이동한다. `B`의 규칙·참조가 웹 증명과 같은지 확인한다.
3. 전제 또는 목표를 수정한다. 이전 재생이 멈추고 새 추론 실행을 안내하는지 확인한다.
4. 긴 수식·긴 증명에서 생략 범위와 전체 수식 텍스트를 확인한다. reduced motion에서도 같은 증명과 설명이 유지되는지 확인한다.

## 검사와 한계

`node --test tests/inference-video.test.mjs`의 6개 테스트는 입력 고정, 모형 결과 보존, 역순 시간 탐색, 참조·자막, 미도달 결과 한계, 단계별 최소 시간, 시간 기반 애니메이션과 reduced motion의 의미 일치, 표시 기호 변환과 원본 입력 보존을 검사한다. 이는 실제 브라우저의 시각 검사를 대신하지 않는다. 브라우저 결과는 통합 작업의 구현 현황/검사 기록에 별도로 남긴다.

이 구현은 HTML 재생 미리보기다. 최종 영상 파일·프레임/오디오 진단·공개 manifest 잠금은 구현하지 않는다. 긴 수식이나 작은 화면의 가독성은 웹 증명·전체 텍스트와 함께 검토해야 한다.

`npm run preview:manifest` (또는 `node scripts/preview-manifest.mjs`)는 기본 예시의 timeline·VTT·시점별 의미 진단·의존 파일 SHA-256을 `artifacts/inference-preview/`에 기록한다. 같은 코드와 입력은 같은 manifest를 만든다. 이 로컬 검토 기록은 출판 manifest나 픽셀/실제 미디어 렌더 검증 결과가 아니다.

목표 미도달은 일반적인 증명 불가능성이나 현실의 거짓을 뜻하지 않는다. 과학적 내용·원자료 판본·권리 검토와 공개 승인은 완료되지 않았으며, 화면 피드백을 출처 검증이나 공개 승인으로 취급하지 않는다.
