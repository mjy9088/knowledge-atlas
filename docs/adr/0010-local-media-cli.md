# 0010 — 독자용 웹과 로컬 영상 제작 도구 분리

2026-10-16. 로컬 구현. 피드백 `feedback:2026-10-16.cli-media-boundary`.

MP4 변환과 영상 파일 제작은 독자의 지식 탐색 기능과 별개다. 공개 JAMstack 빌드에는 렌더 페이지·인코더·muxer를 넣지 않으며, 공개 메뉴에 제작 도구 링크나 CLI 변환 안내도 넣지 않는다. 웹 자산을 디렉터리 전체 복사하는 방식 대신 명시적 `PUBLIC_WEB_FILES`로 관리해 새 제작 파일이 우연히 공개되지 않게 한다. HTML 애니메이션 재생·인터랙티브 추론과 화면 비교는 별도의 읽기/검토 기능으로 보존한다.

MP4 변환은 `scripts/encode-mp4.mjs`와 기존 npm `render:mp4` 명령을 사용한다. 입력과 출력 경로만 받아 mise FFmpeg/ffprobe를 실행하고 H.264·해상도·길이·무음·해시를 진단 파일로 기록한다. `--help`를 제공하고 잘못된 인자는 외부 도구 실행 전에 거절한다. 기존 파일 덮어쓰기는 거절한다. 이 CLI는 별도 웹 서버나 공개 호스트를 필요로 하지 않는다.

개발 서버의 `/api/render/mp4`와 `/renders/` 매핑은 제거한다. 기존 WebM 생성 화면은 개발 서버에서 직접 여는 로컬 보조 도구로 유지하며 MP4 UI·자동 변환을 제거한다. 이 변경은 프레임 생성 전체를 CLI로 이식한 작업이 아니다. 과학 모형·영상 원본·Claim/Source/승인 상태는 변경하지 않았다.

검사: 공개 산출물에 제작 파일·링크·변환 UI/API 문자열이 없는지 회귀 검사한다. CLI 도움말·잘못된 인자 거절과 기존 MP4 preflight를 검사하고, 실제 10초 시험 WebM을 CLI로 변환해 ffprobe 결과를 확인한다. 외부 배포나 공개 승인은 별도다.
