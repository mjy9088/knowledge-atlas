# ADR 0017 — Question-led comparisons in the shared reader

- Date: 2026-10-16
- Status: Implemented locally; content and reader evaluation pending

Add three independently owned topics through the existing catalog: binary search, sphere cross-sections, and base-rate reasoning with a fictional factory. Each starts from a concrete question, supports meaningful observation and changed conditions, and includes an invitation to apply the explanation. Predictions and answer reveals are optional and do not gate navigation.

Use small pure models and explicitly registered domain adapters rather than a generic numeric-control engine or per-topic page/controller. Retain the existing detached state, validated atomic restoration, explicit reset, and deterministic seek contracts. Topic-specific narration must stay applicable to the current scene after reader edits. The static article remains readable without running the interaction.

The factory counts are mathematical expectations in a declared fictional model, not measured production data or medical advice. The sphere drawing is an exact geometric cross-section represented schematically. Binary-search comparison counts concern a declared sorted list and algorithm, not elapsed computer time or arbitrary unsorted input. Each topic owns scoped claims and precise source locators; original scientific fixtures remain unchanged.

Authoring requirements live in [Content structure](../CONTENT-STRUCTURE.md) and [Product](../PRODUCT.md). Automated model, state and geometry checks do not establish learning effectiveness. Source snapshots, independent content review, observed reader comprehension, and publication approval remain separate pending work. No video projection is added by registering these web explanations.
