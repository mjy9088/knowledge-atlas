# 0011 — 한 화면의 읽기와 주제별 추론 어댑터

2026-10-16. 로컬 구현 후보. 피드백 `feedback:2026-10-16.viewport-rule-adapters`.

## 화면 계약

읽기 장면은 FHD 전체화면 1920×1080과 창 테두리·주소창·작업표시줄을 제외한 1920×940을 기준으로, 제목·입력·도표·대사·이동 버튼이 페이지 스크롤 없이 보이게 한다. 1920×900에서도 기본 예시의 목록/도표/본문을 확인한다. 단순히 문서 넘침을 숨기는 것만으로 완료로 보지 않고 실제 컨트롤의 경계와 내부 콘텐츠 높이를 측정한다. 모바일 390×844도 별도로 확인한다.

`reader-frame.css`가 읽기 프레임의 높이를 viewport에 맞추고, 그 안에서 가용 높이를 도표에 배분한다. 연관 지식·근거/범위는 `reader-panels.mjs`의 별도 dialog로 옮긴다. 마지막 장면에는 작은 연결 링크를 표시한다. 메뉴의 긴 근거 목록과 극단적으로 긴 입력/다수 도출 행은 그 영역 안에서 탐색할 수 있다. JavaScript를 사용하지 않으면 사전 생성된 본문 전체를 일반 문서로 읽는다.

## 계산과 표현

공통 `mountPremiseExperiment`는 `derive` 어댑터와 문법 안내를 받는다. 기본값은 기존 고전 명제논리 모형이며 기존 페이지/영상의 계산 의미를 바꾸지 않는다. `mountInferenceExplorer`가 각 어댑터의 동일한 `{goal,lines,goalReached,ruleLabels}` proof를 받아 도표·참조 행·선택 가능한 추론 목록을 그린다. 입력 변경 시 현재 모형의 결과로 대사를 갱신하고, 구문 오류에는 이전 결과를 지운다. 사용자 수정은 장면 이동 중 유지한다. 상태/초기화/검사 API에는 실험과 선택한 시각화 행을 포함한다. 새 영상 타임라인을 구현한 것은 아니다.

| 페이지 | 실제 구현 | 의미의 한계 |
| --- | --- | --- |
| 일관성 | 기존 고전 명제논리 | 불완전한 유한 전방 탐색 |
| 초일관 논리 | FDE의 ¬·∧·∨ 네 값 평가, 최대 5개 원자 | 지정값 보존 전수 확인 또는 구체적 반례. 모든 초일관 논리의 구현이 아님 |
| ZFC | ∈ 전달, ⊆ 추이성, 상호 포함에 대한 외연성 적용 | 이름 붙은 집합 관계의 제한된 계산. ZFC 전체 증명기나 일관성 판정기가 아님 |
| CH/독립성 | Con(ZFC), 두 상대일관성 결과, 두 비증명 결과, 독립성의 연결 | 출처의 등록 정리를 사용하는 메타 수준 도표. 구성가능 우주/강제법의 증명이나 CH 진릿값 계산이 아님 |

FDE 모형은 원자에 참 쪽/거짓 쪽의 두 비트를 주고, 부정은 비트를 교환하며 ∧·∨는 출처의 표에 맞춰 계산한다. 전제가 모두 지정값(T/B)이고 목표는 아닌 평가가 있으면 반례를 그대로 보여준다. 이는 단순한 탐색 실패보다 강한 결과이며 기존 고전 탐색 실패 문구와 구분한다. →·⊥는 이 어댑터에서 거절한다.

집합 관계 모형과 CH 연결 모형의 미도달은 해당 모형이 표시하는 경로를 찾지 못했다는 뜻이다. 알려진 정리를 임의로 생성하지 않으며, CH를 추가한 확장과 ¬CH를 추가한 확장을 같은 이론으로 합치지 않는다.

## 콘텐츠와 검사

기존 Article/Block/Claim ID와 원본 문장은 보존했다. 새 설명은 새 block ID, FDE 의미론·집합 관계·외연성은 새 Claim ID 3개로 추가했다. 출처 조사와 범위는 `RELATED-SOURCE-REVIEW.ko.md`에 기록한다. 새 연구논문의 도표/원문은 복제하지 않았다. 원문 해시·권리 감사·전문가 승인·공개는 미완료다.

제거했던 제작 파일명이나 문구가 빌드에 없다고 나열하던 assertions는 삭제했다. 기능 계약인 링크 해석·해시 재현성·HTML 이스케이프는 유지한다. 새 모형은 출처의 네 값 표, 실제 반례, 유한 집합 해석에서 각 도출의 보존, 메타 추론의 가정 의존성, 어댑터의 오류 제거/초기화를 검사한다. 기존 과학 정답 fixture는 바꾸지 않았다. 이 검사들은 독립적인 전문가의 수학 검토를 대신하지 않는다.
