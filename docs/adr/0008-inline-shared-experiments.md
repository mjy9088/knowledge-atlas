# 0008 — 해설 안의 실험과 공통 입력 컴포넌트

2026-10-16. 상태: 논리 파일럿에 로컬 구현. 사용자 피드백 `feedback:2026-10-16.inline-experiment`를 일반 제작 원칙으로 반영한다.

## 목적과 적용 범위

변수·전제·목표를 바꾸는 것이 이해에 의미 있는 해설에서는 그 자리에서 실험할 수 있게 한다. 처음 보이는 값은 제안 예시다. 별도 실험실로 이동하는 것이 실험의 필수 경로가 되어서는 안 된다. 전용 페이지는 비교·긴 증명·큰 데이터 조작 등으로 이해를 더 돕는 경우에 제공한다. 같은 종류의 조작은 페이지마다 재작성하지 않고 공통 모형·입력 컴포넌트·결과 표현을 재사용한다.

영상에도 가능한 한 같은 체크박스·필드·선택 상태와 실제 값 변화가 보이게 해, 웹에서 값을 바꿔볼 수 있다는 점을 별도 해설 없이 유추할 수 있도록 설계한다. 영상 파일의 입력칸 자체가 조작 가능한 것은 아니다. 가시성만으로 실제 이용자의 발견 가능성을 입증했다고 주장하지 않으며, 필요할 때 짧은 웹 링크나 안내를 보완한다. 모든 지식 페이지에 상호작용을 억지로 추가하는 규칙은 아니다. 상수·정의·원자료의 고정된 조건은 수정 가능 변수와 구분한다.

## 이번 구현

- `premise-experiment.mjs`: 기존 `deriveProof`를 쓰는 `createPremiseExperiment`, 문자열/포함 여부 정규화·오류 시 `proof:null`을 반환하는 평가 함수, `mountPremiseEditor`, 해설용 `mountPremiseExperiment`를 제공한다. 공통 CSS는 `premise-experiment.css`다.
- 현재 재사용 범위는 **최대 8개 기호 명제 전제·목표를 다루는 제한된 명제논리**다. 물리의 단위나 관측 데이터 편집을 지원한다고 주장하지 않는다. 다른 유형에는 별도의 검증된 모형·필드 어댑터가 필요하다.
- `/lesson.html`은 대사창 위에서 전제 포함/제외, 식·목표 편집, 전제 추가/삭제와 ‘장면 예시로’ 복원을 제공한다. 입력을 바꾸면 도표를 즉시 다시 계산한다. 오류·목표 경로 미발견이면 이전 도출 도표를 제거한다.
- 사용자가 수정한 입력은 장면 전환·건너뛰기로 덮어쓰지 않는다. `suggest`는 현재 장면의 제안값만 갱신하고, 명시적 `reset`에서만 그 값으로 복원한다. 수정하지 않은 상태에서는 설명 경로의 목표 Q/R/S와 전제 제외를 따른다.
- 해설의 기존 문장과 사용자 실험이 다를 때는 대사창을 ‘기본 예시 해설’로 표시하고 현재 결과와 구분한다. 사용자 입력을 기본 예시의 증명으로 오인시키지 않는다. 과학 원본·claim ID·정답 fixture는 보존했다.
- 전용 추론 실험실 `app.mjs`도 기존 입력 행 생성·수식 바인딩·추가/삭제 처리를 같은 `mountPremiseEditor`로 교체했다. 기존 상태 API, 제한 탐색, 자동 단계 진행과 오류 시 도표 제거 동작은 보존한다.
- 영상 cue의 `presentation.controlState`는 같은 전제 식/포함 여부/목표 계약을 가진다. 세로 HTML은 공통 편집기를 읽기 전용으로 표시하고, Canvas 렌더는 같은 값을 체크박스·목표 필드로 그린다. 새 모델 계산을 별도로 만들지 않는다.
- ‘이 설명은 알아요’ 위에 건너뛸 지식과 도착 주제를 항상 표시하고 `aria-describedby`로 연결한다. tooltip만으로 설명하지 않는다.

## 상태와 재사용 계약

입력은 `{premises:[{formula,enabled}],goal,customized}`다. 문자열 전제 배열도 제안값으로 받는다. `getState/setState/reset/inspect/suggest`는 복사된 상태를 사용한다. 불완전한 수식은 사용자 draft로 보존하고 계산 결과만 무효화한다. 잘못된 구조나 8개 초과 입력은 이전 상태를 변경하지 않는다. 모형 API의 기존 과학 한계를 상속한다.

해설의 `window.__atlasLesson.getState()`는 `{sectionId,experiment}`를 반환한다. `setState`는 이를 복원하며, 이전 `{sectionId}` 상태도 받는다. `window.__atlasLessonExperiment`는 입력의 독립 검사 API다. 읽기 장면의 시간 호환 `seek`와 영상 시간표는 보존한다.

## 검증과 남은 범위

단위 검사는 입력 유지·제안 복원·잘못된 수식 결과 제거·비활성 전제 제외·상태 분리·지원하지 않는 입력·cue와 모형의 동등성을 확인한다. 기존 의미 fixture는 변경하지 않는다. 데스크톱/좁은 화면과 기존 실험실에서 실제 조작을 확인한다. 자동 회귀 검사와 시각 확인은 독립적인 과학/권리 승인이나 실제 사용자의 발견 가능성 검토를 대신하지 않는다.
