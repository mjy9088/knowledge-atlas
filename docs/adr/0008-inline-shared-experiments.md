# ADR 0008 — Inline shared experiments

- Date: 2026-10-16
- Status: Implemented in the pilot; model adapters extended by 0011

Where changing assumptions helps understanding, embed editable examples inside the explanation. Preserve customized input across navigation; reset explicitly to the current scene suggestion. Reuse the editor and validated model rather than require a separate test page. Dedicated labs remain useful for specialized comparisons.

Both dialogue and diagrams must use the current model result or invalidate together. Do not retain fixed-example narration beside changed input. Unsupported drafts remain editable while stale results disappear. Deterministic templates identify model rows and claim references; generated text is not the calculation engine.

Explain skip scope and destination visibly near the skip button. Use comparable fields/checkboxes and visible value changes in projections to suggest web experimentation, adding guidance when necessary. This is not a mandate to make every definition interactive.

The editor allows eight premises; bounded scrolling for expanded user input is permitted, but default reading examples must fit under the later ADR 0011 contract. Product and Architecture own current state/layout details.
