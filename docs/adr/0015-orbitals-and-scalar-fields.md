# ADR 0015 — Hydrogenic orbitals and generic scalar-field views

- Date: 2026-10-16
- Status: Implemented locally; content/rights review pending

Add the first natural-science article under `content/quantum-physics/atomic-orbitals/`, through the existing catalog and reader. Keep the eight explanatory scenes separate from runtime evaluation. Register the sources, scoped claims and concepts; preserve the original formal-logic content and fixtures. Scope the model to fixed-nucleus, nonrelativistic one-electron s/p/d states with n≤4 and Z≤3.

Use a pure normalized Coulomb model and a domain-neutral scalar-field sampler/Canvas viewer. Support cloud, direct slice and approximate isosurface modes with deterministic state and no automatic motion. The topic adapter supplies amplitude, density weighting, controls and narration. Renderer resolution, tail truncation, sign colors, density thresholds and auto-framing must remain explicit; surface thresholds are not enclosed probabilities.

Use a registered `interactive` adapter rather than force spatial inputs through a symbolic premise editor or create another page/controller copy. Maintain detached getState/setState/reset and independent seek for the static scene. Keep the complete catalog separate from the explosion article's explicitly named related collection. A new topic is not automatically a conceptual relation to the pilot.

References and scope are in [Orbitals](../ORBITALS.md); reusable API and numerical limitations are in [Scalar fields](../SPATIAL-FIELDS.md). The implementation uses independently written equations/geometry without external artwork or code. MIT/OpenStax NC-SA notices and NIST DLMF copyright restrictions remain pending publication review. No immutable source bytes, independent expert approval, new media render or publication is claimed.
