# 약 3분 추론 설명 — 로컬 미리보기

원본은 `content/formal-logic/explosion/lesson.mjs`의 `lesson:logic.inference.three-minutes.ko`다. 가상 버튼·표시등·알림 예시는 자체 작성한 설명 제안이며 실제 기기 동작을 주장하지 않는다. 독자가 기호를 안다고 가정하지 않고 기초부터 읽도록 작성했다. 상위 웹 개요의 `block:intro`에도 전제·추론·모순·폭발의 최소 설명을 추가했다. 기존 모형/과학 fixture는 변경하지 않았다.

| 시간(기본 예시) | 내용 |
|---|---|
| 0:00–0:10 | 추론: 가정에서 규칙으로 결론을 얻는 과정 |
| 0:10–0:20 | P·Q·R을 문장에 붙인 이름으로 읽는 가상 예시 |
| 0:20–0:30 | →를 “만약 …라면”으로 읽고 두 근거 확인 |
| 0:30–0:40 | 전제는 출발점인 가정 |
| 0:40–0:50 | 목표는 얻고 싶은 결론 |
| 0:50–1:00 | 행 번호와 근거 → 규칙 → 결론 읽기 |
| 1:00–2:12 | 각 proof 행의 관찰과 규칙 설명, 기본 5행 × 14.4초 |
| 2:12–2:24 | 목표와 결과 대조 |

| 2:48–3:00 | 가정·근거·규칙·결론 요약 |

여섯 기본 예시 모두 약 180초다. 긴 입력의 증명은 행별 관찰/설명 각각 최소 1.8초를 보존하므로 3분을 넘을 수 있다. 최대 3분에 맞추려고 긴 증명을 압축하지 않는다. 3분 분량은 무음 HTML 타임라인의 길이이며 음성 녹음/TTS 시간으로 검증하지 않았다.

`createVideoTimeline(input,{expanded:true})`가 version 3, 안정 cue ID·phase·title·claimRefs를 가진 확장 타임라인을 만든다. 기존 단순 타임라인은 기본 옵션(version 2)으로 유지한다. 실제 웹/세로 UI와 preview manifest는 확장 모드를 사용한다. 같은 proof 행을 두 cue로 설명하며 과학 계산을 새로 생성하지 않는다. `frameAt`과 세로 `seek`는 순서에 관계없이 같은 시점을 재현한다. VTT·JSON·진단·의존 해시는 `node scripts/preview-manifest.mjs`로 재생성한다.

새 기초 Claim `claim:logic.inference.proof-structure`는 [forall x 17장 §17.1](https://forallx.openlogicproject.org/html/Ch17.html)의 전제·행 번호·정당화 설명에 대응한다. 현재 공식 HTML을 이번 작업에서 읽었다. 기존 규칙 설명은 등록된 ∧/→/∨/모순 관련 Claim을 참조하고, 모형의 제한은 현재 입력 계약에 따른다. 원문 문장·매체를 복제하지 않았다. 등록 판본과 바이트 단위로 일치하는 원문 snapshot, 권리 감사, 사람의 내용 승인, 공개는 여전히 대기 상태다.
