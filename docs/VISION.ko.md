# 비전 및 프로젝트 원칙 (상위 기준 문서)

> 2026-10-16 / 초기 설계 초안. 이 문서의 목적은 기술 선택이나 첫 영상의 기획보다 우선한다.

## 1. 무엇을 만들려는가

과학 전반에 걸친 지식을 **위키처럼 자유롭게 타고 들어가며 읽는 즐거움**에 좋은 시각·청각·상호작용 경험을 더한 웹 기반 지식 지도. 이용자는 특정 관심사를 찾아 들어간 뒤 개념·현상·가정·근거·관련 개념을 자기 순서로 탐색한다. 컨텐츠는 단순한 짧은 자극보다 **지적 유희와 실제 이해의 성장**을 돕는다.

- 특정 저자가 모든 내용을 직접 알아야만 공급할 수 있는 구조를 지양한다. 지속적으로 관리되는 공개 교재·백과·지식 데이터·교육 자료를 원자료로 활용한다.
- 분야는 **형식과학에 한정되지 않는다**. 형식과학은 우연히 처음 검토한 파일럿 주제다. 자연과학, 컴퓨터·공학, 통계, 인지·사회과학과 분야 간 연결도 다룬다.
- 콘텐츠 제작 단계에서 ‘조회수가 높을/재미있을 주제’를 우선 선별하지 않는다. **지식 구조와 출처 가용성·설명 공백·재사용성**이 제작 우선순위의 기본이다.
- 재미는 놀라운 예외나 반전을 강제로 집어넣어 달성하지 않는다. 이용자가 이해하고, 직접 실험하고, 다른 지식과 연결할 때 자연스럽게 발생하도록 한다.
- **큐레이션**은 제한적이다. 어떤 영상/경로에서 무엇을 어떤 맥락으로 언급할지와 연결 안내를 조절하는 정도이며, 지도의 전체 지식 구조를 임의의 스토리 중심으로 자르는 작업이 아니다.
- 동영상은 **별도의 콘텐츠 원본이 아니라** 웹 원본과 모형에서 특정 탐색 경로와 상태 변화를 고정해 재생한 projection이다. 영상만 봐도 그 영상의 설명은 완결되어야 한다.

## 2. 핵심 문제

1. 양질의 과학 자료는 존재하지만 분야마다 흩어져 있고, 어떤 설명은 너무 얕거나 복잡하며, 연결을 따라가기가 어렵다.
2. 글만으로는 시간 변화·조건 변화·공간적 관계·수학적 모형·논증 과정을 이해하기 어려운 경우가 있다.
3. 수많은 웹 인터랙티브를 수작업으로 제작·검증·수정하면 공급량이 늘수록 유지비가 급증한다.
4. 원자료는 바뀌고 과학적 설명은 정정된다. 생성한 시각화·음성·영상·링크가 낡거나 서로 모순될 수 있다.
5. AI의 빠른 생성은 강점이지만, 그럴듯한 오류와 재생성으로 인한 이전 수정 소실을 방지해야 한다.

## 3. 결과로 기대하는 경험

- 이용자는 검색, 링크, 주변 개념을 통해 어디서든 시작할 수 있다. 선행 콘텐츠 강제 이수 없음.
- 기본 설명만 읽거나 재생해도 해당 단위가 약속한 내용을 이해할 수 있다. 상호작용은 선택 사항이지만 사용할 때 의미 있는 차이를 만든다.
- 설명 도중 현재의 변수를 바꾸거나 중간 단계/가정/근거를 확인하고 원래 진행으로 복귀할 수 있다.
- 과학적으로 확립된 결과, 특정 모형의 결과, 관측 데이터, 연구 가설, 아직 결정되지 않은 문제를 명료하게 구분한다.
- 더 자세히 알고 싶은 경우 근거·원자료 판본·다른 설명으로 이동할 수 있다.
- 콘텐츠 오류나 시청각 문제를 문단/장면/상태 단위로 신고할 수 있고, 수정 및 정정 이력은 남는다.

### 해설 안에서 바꿔보는 경험과 재사용

- 조건·전제·목표·변수 변경이 이해를 돕는 경우, 해설을 읽는 같은 자리에서 값을 편집하고 결과를 비교할 수 있게 한다. 기본값은 출발 예시이며, 사용자의 실험값을 장면 이동으로 덮어쓰지 않는다. 도표와 대사는 모두 현재 입력에 맞추고, 적용되지 않는 설명은 무효화한다. 변경 전 예시 대사를 별도로 남겨 혼동시키지 않으며, 예시는 명시적인 복원으로 다시 본다.
- 조작 가능한 필드·선택 항목·포함/제외 상태를 직접 보여주고, 영상에서도 같은 시각 언어와 값 변화를 사용한다. 가능하면 ‘웹에서는 바꿔볼 수 있다’는 별도 말 없이도 실험 가능한 웹 원본을 유추할 수 있게 한다. 필요하면 짧은 링크/안내를 보완하며 발견 가능성은 사용자 피드백으로 확인한다.
- 독립 실험실은 긴 비교나 특수 조작처럼 이해에 특별히 도움이 될 때 추가한다. 일반적인 조작을 설명과 무조건 분리하지 않는다. 비슷한 주제를 다루는 여러 페이지는 검증된 공통 모형·입력 컴포넌트·상태/결과 표현을 재사용한다.
- 이 원칙은 모든 지식에 인터랙션을 강제하지 않는다. 상수·정의·원자료가 고정한 조건은 가변 입력과 구분하고, 검증된 모형의 범위 안에서만 조작한다.

## 4. 제작자 측의 목표

- 원자료를 자동 추적·가져오고, **출처를 보존한 지식 단위**로 매핑한다.
- AI가 원자료에 충실한 초안, 설명 방식, 상호작용 명세, 장면 코드, 음성, 영상 편집 데이터를 작성할 수 있다.
- 실행·정적 검사·화면 관찰(CV)·오디오 검사·내용 대조의 결과를 이용해 AI가 반복 수정한다.
- 사람이 필요한 부분에 피드백을 주고 선택적으로 승인하거나 직접 편집할 수 있다. AI가 승인된 수정사항을 자동으로 지우지 않는다.
- 한 번 검증한 과학 모형·표현 도구·테스트·제작 규칙을 재사용해 **콘텐츠를 더 쉽게 공급**한다.
- 외부 원자료 변경이 의미 있는 경우에만 영향받는 부분을 검토/재생성한다. 원자료 갱신과 자동 공개는 별개다.
- 모든 공개 산출물은 추적 가능하고 재현 가능한 판본으로 관리한다.

## 5. 명시적인 비목표

- 쇼츠·조회수·체류 시간·클릭률을 높이기 위한 자동 주제 선택이나 자극적 영상 연출.
- 첫 버전에서 과학 전반에 대한 자체 새 백과사전 집필.
- 사람마다 다른 과학적 사실을 실시간 생성하는 완전 생성형 지식 엔진.
- 모든 개념에 억지로 인터랙션을 넣거나 모든 설명을 영상으로 변환하기.
- 모든 사용자에게 강제 학습 계획, 진도 통제, 성취도 검사 부여.
- 최신 논문을 읽었다는 이유만으로 공인된 과학적 결론 자동 교체.
- 특정 시각화·AI·영상 편집 스택에 영원히 종속되기.
- 첫 영상 전에 대규모 지식 그래프, 전문 편집기 전체, 자체 오케스트레이터를 완성하기.

## 6. 작업 판단 우선순위

1. 의미의 정확성·출처/권리의 추적 가능성
2. 독립적으로 접근 가능한 경험·탐색 자유·접근성
3. 승인된 변경의 보존·재현성·유지보수성
4. 제작 비용·생산량·재사용성
5. 미관·연출 고도화 및 선택적 개인화

예를 들어 TTS와 화면이 보기 좋더라도 핵심 조건을 잘못 설명하면 공개하지 않는다. 반대로 아직 인터랙션을 만들지 못한 노드는 출처가 명확한 정적 설명으로 공개할 수 있다.

## 7. 이 프로젝트의 첫 결과물

**논리의 모순 폭발**은 첫 시스템 테스트를 위한 임의의 한 노드이며 서비스의 주제적 한계를 의미하지 않는다. 목표는 완벽한 논리 강의가 아니라, 신뢰할 수 있는 원자료 → 검토된 설명 → 실행 가능한 인터랙션 → 영상 projection → 구체적 피드백 → 부분 수정/회귀 검사라는 수직 경로를 완성하는 것이다.

그 뒤의 스케일 검증에는 물리적 관계(변수/단위), 관측 데이터(오차/최신성), 생명과학의 과정(단계/모형의 한계) 등 서로 성격이 다른 분야의 콘텐츠를 추가한다.
