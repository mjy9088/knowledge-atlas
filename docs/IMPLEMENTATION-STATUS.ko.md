## 3:4 화면과 현재 행 진행 표시

`feedback:2026-10-16.portrait-progress`로 세로 stage를 1080×1440(3:4)으로 바꾸고 상하 제목/보조 설명 영역을 줄였다. 비교 페이지의 세로 iframe은 조작부를 포함해 1080×1492이며, 패널 너비를 채워 표시한다. 이전 9:16 구성과 40% 상한은 이 화면에 더 이상 적용하지 않는다. 아래 이전 기록은 당시 검사 이력이다.

현재 추론 행은 2.4초 자동 진행 타이머와 같은 시간 동안 배경을 왼쪽부터 채운다. 전제·목표·포함 여부/예시 변경 시 자동 진행을 재시작한다. 일시정지·수동 선택·장면 이탈·미완성 입력은 타이머와 진행 효과를 함께 취소한다. 명시적 setState/reset/seek는 일시정지하며, reduced motion에서는 4단계 채움으로 표시한다.

Node 검증과 기존 38개 테스트 통과(npm 부재로 동일 진입점 직접 실행). 브라우저 데스크톱 비교 화면에서 1080×1440 stage, 중앙 내용 넘침 없음과 좌우 약 0.07px의 반올림 오차만 남음을 확인했다. 전제 수정 직후 같은 행의 배경 채움이 4.17%→6.26%로 증가하고 일시정지 시 취소되는 것을 확인했다. 모바일 iframe의 목표 변경에서도 진행 채움을 확인했고, 비교 페이지 CSS 390px 너비에서 가로 넘침이 없었다. 검토 이미지 `artifacts/portrait-progress/desktop.jpg`, `narrow.jpg`는 로컬/Git 제외다. 과학 모형/주장/출처 및 공개 상태는 변경하지 않았다.

## Scene 1의 재현 범위

웹 초기 상태 및 `reset()`은 `P`, `¬P` 두 전제로 `Q`를 도출하는 상태다. `seek(0)`은 별도 storyboard 초안의 시작 상태(전제 없음/Q)다. 30초 초안에서 6초·12초·18초·24초의 전체 상태를 선택하며, 마지막 시점 이후는 마지막 상태를 유지한다. 이 구현은 상태 재현이며 프레임·음성·자막·영상 렌더가 아니다.

화면 의견을 남기는 방법과 의미상의 경계는 [Scene 1 검토 안내](M1-REVIEW.ko.md)를 참고한다. 과학적 Claim/Source 원본은 이번 작업에서 변경하지 않았으며 source-verified 또는 published로 승격하지 않았다. 실제 피드백 자동 적용·승인 수정 보존 파이프라인은 M4의 미구현 범위다.
