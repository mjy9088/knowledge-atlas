# 개발 백로그 — 첫 영상에서 지속 가능한 시스템까지

각 단계는 구현 코드·문서·테스트·검토된 데모를 함께 갖출 때 완료다. **진행 중인 일**과 **완료된 기능**을 구별한다.

- [x] 원본 / 지식 그래프 / 콘텐츠 / 장면 / projection / 피드백의 개념적 계약 작성.
- [x] 첫 논리 파일럿의 주장·장면·검사 요구사항 기술.
- [x] Git으로 관리 가능한 최소 저장소와 데모/기초 테스트 작성.
- [ ] `SourceSnapshot/Claim/Scene/Projection/Feedback` 전부에 대한 버전별 마이그레이션 정책 확정.
- [ ] 정식 코드/콘텐츠 공개 라이선스 정책(저작자가 결정) 확정.

**DoD:** 에이전트가 다른 대화 기록 없이 저장소에서 목적과 제한을 읽고 작업을 시작할 수 있고, `npm run validate && npm test` 통과.

## M1. 첫 인터랙티브 화면의 독립적 완성 (최우선 개발)

- [x] 첫 장면의 상태 계약을 구현하고 view/controller/model을 분리.
- [x] `getState/setState/reset/seek`의 재현 가능 API. 이벤트 리플레이와 snapshot 비교.
- [ ] 시각/화면 접근성: 반응형, reduced motion, 키보드, ARIA, 스크린 리더용 대체 설명.
- [x] 설명과 상호작용의 연결; 입력 변경 시 보이는 경고·모형 한계 동기화.
- [x] 페이지의 source/claim/version 패널과 실제 지식 노드 링크. 현재 연결은 등록된 개념의 요약 패널이며 독립 상세 페이지는 후속 범위.
- [ ] UI smoke test 및 Playwright 기반 브라우저 검증.

**DoD:** 입력·초기화·상태 재현이 정확하고, 각각의 결과를 사람이 설명할 수 있는 웹 콘텐츠 1개.

2026-10-16: 데스크톱·좁은 화면의 도구 기반 브라우저 확인 및 키보드 일부 조작을 수행했다. 완전한 접근성 검토와 저장소의 Playwright 자동 회귀 suite, 사람의 화면 피드백은 남아 있으므로 M1 전체 완료로 표시하지 않는다. 검사 증거는 `IMPLEMENTATION-STATUS.ko.md`, 화면 피드백 안내는 `M1-REVIEW.ko.md` 참고.

## M2. 웹 장면 → 영상 프레임 수직 경로

2026-10-16 사용자 피드백으로 별도 추론 실험과 HTML 재생 미리보기를 추가했다. 동일 proof snapshot의 시간 기반 강조·자막·좁은 화면 카드는 구현했으나, 사용자가 영상 파일 내보내기를 제외했으므로 아래 실제 프레임/미디어 렌더 DoD의 완료로 세지 않는다. 로컬 preview manifest는 출판 manifest가 아니다.

후속 ‘동영상 렌더러’ 요청으로 추론 실험에 한정한 Canvas/WebCodecs/WebM 어댑터와 mise FFmpeg MP4 변환을 구현했다. 기본 3분 파일과 10초 시험 출력의 검증 기록은 구현 현황을 참조한다. 기존 Scene 1 projection/event schema의 완전한 통합·출판 manifest·환경 간 재렌더 검증은 여전히 남아 있다. 이 초기 기록의 ‘파일 제외’는 현재 로컬 렌더러에 적용되지 않는다.

- [x] 추론 실험의 시각/모형 레이어를 공유하는 로컬 영상 어댑터 결정(Canvas/WebCodecs + mise FFmpeg).
- [ ] 특정 시점 t/frame에서 장면 상태를 독립적으로 재현, frame export.
- [ ] projection schema와 event/timeline, camera/highlight layers 분리.
- [ ] 10~30초짜리 초벌 영상 클립 출력 후 web/snapshot과 의미 비교.
- [ ] 검증 가능한 manifest 기록 및 재렌더 동일성 검사(허용 오차 명시).

**DoD:** 같은 입력/판본에서 웹 상태와 동등한 영상 장면이 렌더된다. 전체 영상 제작 전의 첫 통합 시험.

2026-10-16: 모순 폭발에 초점을 맞춘 134초 무음 본편과 연관 웹 해설 4편을 추가했다. 전체 세로 MP4와 자막/진단을 로컬 생성했으나 음성·출판 manifest·권리/사람 내용 승인은 남아 있으므로 M3 전체 완료로 세지 않는다.

## M3. 첫 영상 전체 제작

- [ ] 내용/장면 구성 최종 검토, 해설 chunk·음성 생성 또는 녹음 및 발음 사전.
- [ ] 자막·강조·전환·읽을 시간·영상 타임라인 작성.
- [ ] AI의 오디오/타임라인 편집과 FFmpeg 기술검사, 스크린샷/CV 시각검사.
- [ ] 정상 재생 가능한 MP4 + SRT/VTT + 출처·저작권 고지/설명란 텍스트.
- [ ] 유튜브에서도 내용을 독립적으로 이해할 수 있는지, 과도한 자극/오해 없는지 검토.

**DoD:** 영상 최종본과 편집 가능한 소스, 검사/렌더 로그가 존재. 미공개라도 이 단계의 제작 작업은 완료될 수 있음.

- [ ] 변경 전후 화면/영상 diff와 승인/거절/되돌리기.
- [ ] F1 (타이밍), F2 (의미), F3 (수정 보존) 실제 수행.
- [ ] 지역 패치와 전역 제작 규칙/fixture를 분리하는 관리 방법 구현.

**DoD:** 이미 승인한 Scene 1 수정은 이후 다른 장면의 재생성에도 보존되고 실패 시 검사에서 드러남.

## 의존성과 순서

```text
M0 ── M1 ── M2 ── M3 ── M4 ── M5 ── M6
       \__________ source/license quality gates _______/
```

M2를 위해 전체 영상 편집기가 필요하지 않고, M3의 자동 오디오 검사가 도입되기 전이라도 M1의 상태/실행 검사는 완료할 수 있다. M4 이전의 자동 생성 범위는 제한적으로 시작 가능하지만 **내용의 승인 없는 자동 공개는 금지**한다.
