사용할 전제

대문자 P, Q, R… · 부정 ¬ · 그리고 ∧ · 또는 ∨ · 조건문 → · 괄호 ( )
예: P → Q, ¬(P ∧ Q) · 전제는 최대 8개입니다.

추론의 흐름

    이 실험의 규칙과 한계

    결합 제거·도입, 조건문 적용, 모순 도출·폭발, 선택적 논리합 도입을 사용하는 제한된 탐색입니다. 못 찾은 증명이 없다는 뜻은 아니며, 현실의 참·거짓도 판정하지 않습니다.

    새 추론 규칙의 설명과 출처 대조는 검토 중인 제안입니다. 원래 모순 폭발 장면과 별도로 검토합니다.
