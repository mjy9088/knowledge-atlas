# Light-clock time episode

## Explanatory contract

This episode asks one bounded question: how an ideal transverse light clock distinguishes a proper-time interval on one clock worldline from a coordinate-time interval assigned in another inertial frame. It assumes constant inertial relative speed `v<c`, invariant vacuum light speed `c`, mirrors separated transversely by `L`, and explicitly treats transverse `L` as equal in both frames. Comparisons at distinct locations use clocks at rest in the other frame, synchronized by assigning equal outward and return light-travel times. It derives

`(c Δt/2)^2 = L^2 + (v Δt/2)^2`, with `2L/c=Δτ`, and therefore `Δt=γΔτ` for positive finite intervals.

The independently computed illustrative case is `v=0.6c`, `γ=1.25`, so `Δτ=8 ns` corresponds to `Δt=10 ns`. It is not historical data. The first comparison selects events `E₁,E₂` on clock A; the reversed comparison selects different events `F₁,F₂` on clock B. It does not turn reciprocal coordinate comparisons into an absolute “slower clock” claim. Acceleration, gravity, reunion paths, and the twin paradox are outside the promised derivation.
