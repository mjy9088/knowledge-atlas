# Rational density in the real numbers

This candidate asks how to find a rational number between arbitrary real endpoints, not only between rational endpoints. It assumes the real numbers and their Archimedean property, chooses a positive integer `n` with `1/n<y−x`, and sets `m=⌊nx⌋+1`. The resulting chain `x<m/n≤x+1/n<y` proves that `m/n` lies strictly inside the interval. The proof does not construct the real numbers, prove the Archimedean property, or appeal circularly to rational density.

The floor formulation handles the boundary case explicitly: using `⌈nx⌉` alone can return `nx` when `nx` is already an integer, while `⌊nx⌋+1` remains strictly larger. The worked case `√2<3/2<√3` uses exact positive-square comparisons rather than decimal approximations. The transfer case compares `n=10`, which reaches the endpoint of `(1,1.1)`, with `n=20`, which gives `21/20`; this makes the strict mesh condition observable.
