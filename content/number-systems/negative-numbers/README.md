# Negative numbers and integers

The episode starts with movement across zero, then defines integers using additive inverses. Debt, loss, and temperature are labeled as motivations rather than constructions. The worked line `−2−(−4)=−2+4=2` grounds the sign rule in `a−b=a+(−b)` instead of asking readers to memorize a slogan. The final `1÷2` boundary leads to rational numbers.
