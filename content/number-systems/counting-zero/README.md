# Counting and zero

The episode moves from an empty box to finite cardinality, additive identity, and the declared convention `ℕ={0,1,2,…}`. It explicitly warns that natural-number conventions vary and keeps positional zero's history separate from the modern definition. The transfer compares `4−4=0` with `4−6=−2`, revealing the next extension without pretending that adding zero makes natural numbers closed under subtraction.

## Empty-set cardinality source provenance

For `claim:number-systems.zero.empty-count`, Oscar Levin's *Discrete Mathematics: An Open Introduction*, fourth edition (Fall 2024), §5.1 “Sets” was consulted on 2026-10-19 at <https://discrete.openmathbooks.org/dmoi4/sec_structures-sets.html>. The opened HTML page identifies `∅={}` as the set containing no elements in the Notation subsection (paragraph permalink `#subsec_notation-7`) and later defines the cardinality of a finite set as the number of elements in that set, immediately before Example 5.1.6. Together these definitions give `|∅|=0`; the source is not represented as printing that equation in a separate theorem.
