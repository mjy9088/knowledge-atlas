# Counting and zero

The episode moves from an empty box to finite cardinality, additive identity, and the declared convention `ℕ={0,1,2,…}`. It explicitly warns that natural-number conventions vary and keeps positional zero's history separate from the modern definition. The transfer compares `4−4=0` with `4−6=−2`, revealing the next extension without pretending that adding zero makes natural numbers closed under subtraction.
