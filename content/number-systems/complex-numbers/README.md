# Complex numbers

This episode constructs complex arithmetic from ordered pairs before using `i²=-1`. Its central representation is an original static SVG showing multiplication by `i` as `(a,b)→(-b,a)`: zero stays fixed, while every nonzero point makes a counterclockwise quarter-turn with unchanged length. Angle language for nonzero points is understood modulo `2π`/`360°`. The episode separately adopts its own expository convention that zero has no direction angle. This is not Beck's convention: §1.2 Geometric Property 7 permits every real number as an angle for zero, while Geometric Property 17 supports argument addition and modulus multiplication for nonzero factors. The order argument first records `i≠0` from `i²=-1`, then applies trichotomy; it is scoped narrowly to the fact that no total order extending the real order can make the complex numbers an ordered field, not to a prohibition on every comparison or partial order.

The transfer computes `i(2-i)` algebraically and geometrically.
