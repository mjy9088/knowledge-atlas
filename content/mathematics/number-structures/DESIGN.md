# Why these number systems?

## Status and authoring contract

This is the current prospective authoring plan, revised after two independent blocking reviews. It is not approval, learner evidence, source clearance, or publication authorization.

Build one coherent explanation around a repeated question: what fails in the current system, what kind of repair is being chosen, and which earlier structure must remain? The main argument is not that each local obstruction forces the next familiar set. In particular, `√2∉ℚ` does not force `ℝ`: inside an already supplied ambient real field, the independently verified construction `ℚ(√2)={a+b√2:a,b∈ℚ}` is the field generated by adjoining that one root and properly extends `ℚ`; the least-upper-bound property is a stronger global requirement covering every nonempty bounded subset. The reader should finish able to distinguish local repairs of named equations from universal structural requirements.

Use `ℕ={0,1,2,…}` as an inline convention; other conventions exist. Treat `ℕ→ℤ→ℚ→ℝ→ℂ` as selected examples, not an inevitable or final ladder. Separate:

- operation, equation, and structural-property goals;
- ordered-field assumptions from completeness;
- existence of one complete ordered field from uniqueness up to ordered-field isomorphism;
- proper field extension from set cardinality;
- an arbitrary comparison from an order compatible with field operations.

An ordered field here means a field with a total order such that `a<b` implies `a+c<b+c`, and `0<a,0<b` imply `0<ab`. Completeness means the least-upper-bound property. A separate Dedekind-cut construction supplies one complete ordered field called `ℝ`; the optional uniqueness argument says every complete ordered field is isomorphic to it. Completeness alone, or Cauchy completeness without the ordered-field package, does not yield that characterization.

### Uniqueness proof obligations

For complete ordered fields `F` and `G`, identify their rational copies through `0` and `1`.

1. **Archimedean premise.** LUB completeness implies that the natural-number copy is unbounded: if `s=sup ℕ`, then `s−1` is not an upper bound, so some `n` satisfies `s−1<n`, hence `s<n+1∈ℕ`, contradicting that `s` is an upper bound. MIT p. 4 supports this premise.
2. **Integer part and rational density.** For arbitrary `z` in an Archimedean ordered field, choose `N∈ℕ` with `N>−z`. The set `{k∈ℕ:k>z+N}` is nonempty by Archimedeanness; by the well-ordering of the standard natural-number copy it has a least `k`. Since `z+N>0`, `k≥1`, and minimality gives `k−1≤z+N<k`. Thus `m=k−N` satisfies `z<m≤z+1`. For `x<y`, choose `n∈ℕ` with `n(y−x)>1`, apply the integer-part lemma to `z=nx`, and obtain `x<m/n≤x+1/n<y`. This generic-field lemma is an independently authored deduction from the sourced Archimedean premise plus the standard well-ordering assumption; do not cite real-only floor claims as if they prove it.
3. **Cut eligibility and strict order.** Integer bounds give `m<x<n`, so `L_x={q∈ℚ:q_F<x}` is nonempty and `{q_G:q_F<x}` is bounded by `n_G`; define `φ(x)` as its `G`-supremum. If `x<y`, choose `x<r<s<y`. Here `r_G` is an upper bound of the defining set for `φ(x)`, not an upper bound of the element `φ(x)`; therefore `φ(x)≤r_G<s_G≤φ(y)`. Hence `φ` strictly preserves order and is injective.
4. **Rational fixing and comparison.** For every rational `a`, prove `φ(a_F)=a_G`. The element `a_G` bounds `{q_G:q<a}`. If `z<a_G`, density in `G` gives `z<q_G<a_G`, so `z` is not an upper bound; therefore `a_G` is the least upper bound. Then prove `q_F<x` iff `q_G<φ(x)`: forward, insert `q<r<x`, so `q_G<r_G≤φ(x)`; reverse, if `q_F≥x`, then `q_G` bounds the defining set and hence `φ(x)≤q_G`.
5. **Surjectivity.** Given `y∈G`, let `A_y={q_F∈F:q_G<y}` and `x=sup_F A_y`. If `q_G<y`, insert `q_G<r_G<y`, so `q_F<r_F≤x`. Conversely, if `q_F<x` but `q_G≥y`, then `q_F` bounds `A_y`, contradicting `x≤q_F`. Hence `q_F<x` iff `q_G<y`; the rational-comparison equivalence also gives `q_G<φ(x)` iff `q_F<x`, so `y` and `φ(x)` have the same lower rational cut. Density in `G` rules out inequality, proving `φ(x)=y`.
6. **Suprema under the order isomorphism.** Once strict order and surjectivity are proved, show explicitly that an order isomorphism preserves a supremum: `φ(s)` bounds `φ[S]` when `s` bounds `S`; if `v` bounds `φ[S]`, then `φ⁻¹(v)` bounds `S`, so `s≤φ⁻¹(v)` and `φ(s)≤v`.
7. **Addition.** Let `S_F={r_F+s_F:r_F<x,s_F<y}`. It is cofinal below `x+y` against every `u∈F`, not merely rational targets: if `u<x+y`, choose rational `r` with `u−y<r_F<x`, then rational `s` with `u−r_F<s_F<y`; thus `u<r_F+s_F<x+y`. The rational-comparison equivalence identifies its transported set in `G`, and the same arbitrary-`G` argument makes that set cofinal below `φ(x)+φ(y)`. Therefore both `φ(x+y)` and `φ(x)+φ(y)` are the same `G`-supremum.
8. **Multiplication and signs.** For `x,y>0`, positive rational approximants exist by density. Let `P_F={r_Fs_F:0<r_F<x,0<s_F<y}`. For arbitrary `u<xy`, any member works when `u≤0`; when `0<u<xy`, choose `u/y<r_F<x`, then `u/r_F<s_F<y`, giving `u<r_Fs_F<xy`. Repeat in `G` using rational comparison, so the two suprema agree. Addition and rational fixing give `φ(0)=0` and `φ(-x)=-φ(x)`; handle zero directly and reduce one- and two-negative-factor cases to positive multiplication. Goldmakher prints the positive case; Baggett p. 229 says the multiplication argument is analogous and records the sign reduction, but does not print the full positive-product cofinality proof. Label that full derivation as independently supplied here.
